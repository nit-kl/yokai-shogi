# Stock Piece Images

今後のラインナップ候補となる駒画像の保管場所です。

- このフォルダの画像は、候補・検討中素材として扱います。
- ゲーム内で使用する確定済み画像は `client/public/assets/pieces/` 直下と `client/public/assets/pieces/sm/` に配置します。
- 実装に組み込むときは、`shared/data.ts` の駒定義、ガチャプール、必要な小サイズ画像もあわせて更新します。
- 公開前に生成手段、利用規約、商用・公開可否、権利帰属を確認します。

## ストック駒のイラストデザイン方針
今後追加するストック駒のイラストは、以下のテイスト・雰囲気で統一します。

1. **トレーディングカードゲーム（TCG）風の美麗なイラストスタイル**
   - 単なるフラットなイラストではなく、ゲームのメインカードとしても映えるような重厚感とクオリティを意識します。
2. **ハイディテールな描き込みと質感**
   - 藁、衣類、毛並み、水などの素材テクスチャを繊細に描き込み、高密度なディテールを表現します。
3. **ドラマチックなライティングと高コントラスト**
   - 強い光源による陰影（ドラマチック・ライティング）を効かせ、キャラクターの立体感や存在感を際立たせます。
4. **躍動的かつダイナミックなポージング**
   - 静的な立ち絵ではなく、技を繰り出している瞬間や空中を舞う姿など、動きと迫力のある構図を採用します。
5. **ファンタジー・エフェクトの付与**
   - 妖怪の属性や能力を象徴するファンタジー要素（風の渦、水の魔法、浮遊する符やお札、鬼火など）の視覚エフェクトを効果的にまとわせます。
6. **透過PNG形式での保存**
   - `client/public/assets/pieces/stock/` に保管する時点では、背景除去を施した透過PNG形式とします。

## ゲーム用 WebP への取り込み

既存駒と同じく **正方形 512px（フル）/ 160px（sm）** に変換する。単純な `contain` だけだと縦長原画の本体が小さく見えるため、次を推奨する。

1. アルファ質量の中央付近でクロップ（細い煙・縄の端を落とす）
2. 正方形へ配置し、細すぎる駒は最大約1.28倍まで寄って本体を大きくする（頭が欠けない範囲）
3. キャンバスの約 94% に配置（既存駒と同程度の大きさ）
