# 百鬼盤 プライバシーポリシー

> 運営者: nit / 最終更新: 2026-08-22

個人開発者nit(以下「運営者」)は、ゲーム「百鬼盤」(以下「本サービス」)における利用者の情報の取り扱いについて、以下のとおり定めます。本サービスにはブラウザ版および Steam 版が含まれます。本サービスは**個人情報の取得を最小化する設計**を採用しており、メールアドレス・氏名・電話番号等は取得しません(doc 06 / doc 11)。

## 1. 取得する情報

| 区分 | 内容 | 取得方法 |
|---|---|---|
| 認証識別子 | 自動発行されるアカウントID、認証トークン(ハッシュ化して保存)、パスキー公開鍵、引き継ぎコード(ハッシュ化して保存)、Steam 版における Steam ID | 自動生成 / 利用者の登録 / Steam 認証 |
| プレイデータ | 所持妖怪・ガチャチケット・妖力・編成・対戦成績・ログイン履歴・通貨増減ログ・広告報酬の受取履歴 | サービス利用に伴い自動記録 |
| 表示名 | 利用者が任意に設定する名称(1〜10文字) | 利用者の入力 |
| アクセスログ | IPアドレス、リクエスト日時、不正対策に必要な技術情報 | 自動記録(短期保持) |
| bot対策情報 | アカウント発行時の Cloudflare Turnstile による検証結果(主にブラウザ版) | 自動 |
| Steam 認証情報 | Steam Session Ticket。アカウント認証のため Valve のサーバーへ送信し、Steam ID を取得します | Steam 版の起動・ログイン時 |
| 広告関連情報(任意) | ブラウザ版でリワード広告を視聴する場合、広告ネットワークが端末識別子・IPアドレス・ブラウザ情報・広告ID等を取得することがあります | 利用者が広告視聴に同意したとき |

- 本サービスは**メールアドレス・氏名・住所・電話番号・決済情報を取得しません**。
- 本サービスは**チャット機能を持ちません**(定型表現を除く)。

## 2. 利用目的

- 本サービスの提供・維持・改善(進行データの保存、複数端末でのデータ同期)
- 不正行為(チート・多重アカウント・自動操作・報酬の不正取得)の検知と防止
- 障害対応・お問い合わせ対応
- 利用状況の統計的な把握(個人を特定しない形での集計)
- リワード広告の配信・効果測定・不正視聴防止(ブラウザ版で利用者が視聴する場合)

## 3. 第三者提供

運営者は、法令に基づく場合を除き、取得した情報を第三者に提供しません。ただし次は例外とします。

- 本サービスはインフラとして Cloudflare(配信・実行基盤・データベース・bot対策)を利用しており、これらは本サービス提供のための委託先(またはそれに準ずるもの)として扱います。
- Steam 版では、Steam アカウントの認証のため、Steam Session Ticket を Valve(Steam)へ送信します。送信の詳細は [Valve のプライバシーポリシー](https://store.steampowered.com/privacy_agreement/) に従います。
- ブラウザ版で利用者がリワード広告を視聴する場合、広告の配信に必要な範囲で、広告ネットワーク(例: Google の広告配信サービス)へ端末・接続情報が送信されます。送信の詳細は各ネットワークのポリシーに従います。**Steam 版では広告を出さず、広告ネットワークへ情報を送りません。**

## 4. Cookie・ローカルストレージ等

本サービスは、ログイン状態の維持・進行データの保持のために、ブラウザまたはデスクトップクライアントのローカルストレージ等(認証トークン・ローカルセーブ・広告視聴同意の記録)を使用します。ブラウザ版のリワード広告利用時は、広告ネットワークが Cookie や類似技術を使用する場合があります。

## 5. 保持期間

| データ | 保持期間 |
|---|---|
| アクセスログ(IP等) | 取得から約30日で自動削除 |
| 休眠ゲストアカウント(約30日間アクセスがなく、パスキーも引き継ぎコードもないもの) | 自動削除の対象 |
| 削除請求したアカウントのデータ | 請求から90日後に物理削除(誤操作からの復元猶予) |
| 対戦のリプレイ用ログ | 一定期間後に集計結果のみを残し削除 |

## 6. 利用者の権利(開示・削除等)

- 利用者は、お問い合わせ窓口から自身のアカウントとデータの削除を請求できます(申請後、アカウントを停止し、原則90日後に物理削除します)。
- その他、保有情報の開示・訂正・削除等のご請求は、お問い合わせ窓口にて対応します。本人確認のため認証識別子等の確認をお願いする場合があります。

## 7. 未成年の利用

本サービスはユーザー課金を伴わないため、高額決済等のリスクはありません。ブラウザ版のリワード広告の視聴は任意であり、日次の上限があります。Steam 版には広告がありません。表示名には不適切表現のフィルタを設けています。

## 8. 海外からの利用

本サービスは日本国内の利用者向けです。文言の正本は日本語とし、英語UIは便宜のために提供します。準拠法は日本法とします。

## 9. 改定

本ポリシーは予告なく改定されることがあります。重要な変更はゲーム内のお知らせ等で告知します。
