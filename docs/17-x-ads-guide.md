## 2. X広告の重要ポリシー（審査落ち回避）

### 2.1 ハッシュタグ禁止（最重要）

**2025年6月27日以降**、X広告の本文に `#`（ハッシュタグ）を含めると配信停止（Halted）になる。

- オーガニック投稿: ハッシュタグ OK
- **有料広告: ハッシュタグ NG**
- ハッシュタグ付き既存ポストを「プロモート」するのも NG

```
❌ #百鬼盤 #ブラウザゲーム #無料ゲーム
✅ ハッシュタグなしの本文のみ
```

参考: [ハッシュタグを含むX広告の配信停止](https://ppc-log.com/twitter-ads/16565/)

### 2.2 本文への URL 直書き禁止

- 本文に `https://...` を書かない
- **ウェブサイトカード**（URL欄・見出し欄）で設定する

### 2.3 その他

- 日本/韓国向け: 絵文字 `#⃣` `✅` の単体使用も禁止の報告あり
- 広告の訴求（無料・インストール不要）と LP の内容を一致させる
- 動画・画像にポリシー違反要素がないこと

## 3. タイムゾーン（PDT ↔ JST）

広告アカウントのタイムゾーンは**作成後変更不可**（変更する場合はサポート経由で新規アカウント作成）。

アカウントが **PDT（太平洋夏時間）** の場合、日本向け配信時刻は次式で換算する。

```
JST = PDT + 16時間
入力する PDT = 希望する JST − 16時間
```

| 意図（JST） | Ads Manager 入力（PDT） |
|---|---|
| 6/20 9:00 開始 | 6/19 5:00 PM |
| 6/28 0:00 終了 | 6/27 8:00 AM |
| 6/28 23:59 終了 | 6/28 7:59 AM |

## 5. UTM パラメータ

ランディング URL に付与する計測用ラベル。ゲームの動作は変わらない。

| パラメータ | 例 | 意味 |
|---|---|---|
| `utm_source` | `x` | 流入元 = X |
| `utm_medium` | `paid` | 手段 = 有料広告 |
| `utm_campaign` | `traffic_v2` | キャンペーン識別子 |

**入力方法（Ads Manager）**

- ウェブサイト URL: `https://yokai-shogi.nit-games.com/`
- URL パラメータ欄: `utm_source=x&utm_medium=paid&utm_campaign=traffic_v2`

版を変えるたびに `utm_campaign` の suffix を更新する（`traffic_v1`, `traffic_v2`, …）。

## 6. 「ポスト」「広告」「キャンペーン」の関係

| 概念 | 場所 | 説明 |
|---|---|---|
| **ポスト** | クリエイティブ → ポスト | X 上の投稿本体。オーガニックでも閲覧可能 |
| **広告（Ad）** | キャンペーン → 広告グループ → 広告 | ポスト + 配信設定の組み合わせ |
| **キャンペーン** | キャンペーンフォーム | 予算・目的・期間の入れ物 |

**よくある勘違い**

- ポスト画面に v2 があっても、キャンペーンの「広告」に v2 が紐づいていなければ **配信されない**
- Analytics に v1（Halted）だけ見える → キャンペーン側で v2 広告を作成・公開できていない
- ポストを削除しなくてもよい。停止すべきは **旧キャンペーン**

## 7. 公開後の運用フロー

### 7.1 公開直後（〜24時間）

1. Ads Manager → **Analytics → 広告** タブ
2. 配信ステータスを確認
   - **Active / Running** → 正常
   - **Halted** → §8 トラブルシュートへ
3. インプレッションが 0 から増え始めるか（数時間以内）

### 7.2 定期確認（3日目・7日目）

| 指標 | 目安 | 確認場所 |
|---|---|---|
| インプレッション | 日予算 500円なら数百〜 | Ads Manager |
| リンククリック | 数十/週 | Ads Manager |
| CTR | **0.5% 以上**が合格感 | Ads Manager |
| CPC | 50〜150円程度（初回） | Ads Manager |
| 新規ゲスト数 | 広告前後で増加 | Analytics Engine（doc analytics-queries.md） |

### 7.3 改善サイクル

```
数字確認（3日）
  ↓
CTR 低い → 動画冒頭 or 見出しを変更 → 新規広告（v3）
CPC 高い → ターゲットを絞る（興味関心を Gaming のみ等）
反応良い → 日予算 500 → 1,000 に段階増
  ↓
旧キャンペーン Pause / Delete
```

### 7.4 旧キャンペーンの扱い

| 操作 | いつ |
|---|---|
| **Pause** | v2 公開後、v1 を止める（課金なし） |
| **Delete** | 一覧整理。Campaign actions → Delete campaign |
| ポスト削除 | **不要**（オーガニック流入経路として残してよい） |

## 8. トラブルシュート

### 8.1 Halted（停止）

広告が審査で止まり、配信されない。

**確認順**

1. 本文に **ハッシュタグ** がないか（最有力）
2. 登録メールの却下理由
3. 広告詳細のポリシー名
4. X Premium 認証状態
5. LP（規約・プライバシー・広告訴求の一致）

**対処**

- 原因を修正し、**新規キャンペーン + 新規広告** で再出稿
- 同じ Halted 広告への再異議申し立ては効果が薄い

### 8.2 Appeal declined

**自分で異議申し立てしていなくても** この表示になることがある（内部ステータス名の表示）。

意味: **この広告は配信不可と判定された**。

→ §8.1 と同様、修正して新規作成。

### 8.3 数字がすべて 0

- Halted なら正常（配信されていない）
- Active なのに 0 → 開始時刻（PDT/JST）、日予算、ターゲットが狭すぎないか確認

### 8.4 クレカ 804円請求

カード登録時の **約$5 仮押さえ**。広告費ではない。通常 7 日以内に解除。

### 8.5 ポストは見えるが広告が回らない

- ポスト = オーガニック公開（問題なし）
- キャンペーンが Halted / Pause / 未公開

## 12. リリース記念キャンペーン（2026-07 / v3）

オンライン公開記念の**ガチャチケット100枚配布**をフックにしたサイト誘導。  
ゲーム内キャンペーン ID: `release-2026-07`（お一人様1回・オンボ完了後に自動付与）。告知期限の目安は 2026-08-18 まで（`shared/announcements.ts`）。

### 12.1 訴求の注意

| 使う | 使わない |
|---|---|
| ガチャチケット100枚 / 100枚プレゼント | 「100連確定」「SSR確定」など誤解を招く表現 |
| オンライン公開記念・リリース記念 | 「今だけ全員に課金アイテム」など課金連想 |
| 無料・登録不要・ブラウザですぐ | ハッシュタグ・本文への URL 直書き |

ガチャ UI は 1回／10連のみ。広告でも「100連ガチャ」ではなく**チケット100枚**と書く。

### 12.2 推奨設定（v2 との差分）

手順は §4 と同じ。名前とクリエイティブだけ差し替える。

| 項目 | 値 |
|---|---|
| キャンペーン名 | `百鬼盤_リリース記念_v3` |
| 広告グループ名 | `百鬼盤_日本_リリース記念_v3` |
| 広告名 | `百鬼盤_チケット100枚_v3` |
| 目的 | ウェブサイトトラフィック |
| 日予算 / 合計上限 | JPY **500** / **5,000**（初回と同額で開始） |
| 配信時間 | 原則 **JST 19:30〜21:30** に寄せる（doc 18。常時薄配は避ける） |
