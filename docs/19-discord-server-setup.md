# 19. Discordサーバー作成・運用手順

妖怪将棋の公式Discordを新規作成し、安全に公開して対戦募集を開始するまでの実作業手順。
PC版またはブラウザ版Discordを基準とする。Discordの画面名が変更された場合は、同じ目的の
「サーバー設定」「安全設定」「コミュニティ」「ロール」項目を選ぶ。

## 0. 作成前に決めること

| 項目 | 初期値 |
|---|---|
| サーバー名 | `妖怪将棋 公式コミュニティ` |
| 主目的 | 毎日20:00〜22:00のランダムマッチと公式対戦会への集合 |
| 所有者 | 運営代表者の業務用Discordアカウント |
| 問い合わせ | `#感想・不具合報告`。個人DMでは受け付けない |
| 公開範囲 | 招待リンクを公式サイト・公式Xで公開 |
| 初回対戦会 | 公開日の3日後以降、土曜21:00〜22:00 |

個人用アカウントを所有者にしない。所有者アカウントはメールアドレスを確認し、長く使える
パスワードと多要素認証を設定する。バックアップコードはパスワード管理ツール等へ保管する。

準備する素材:

- 正方形のサーバーアイコン
- ゲームURL `https://yokai-shogi.nit-games.com/`
- 利用規約・プライバシーポリシー・問い合わせ先のURL
- `#はじめに` とルールへ掲載する文章（本書にテンプレートあり）
- モデレーターを置く場合は本人のDiscordアカウント

## 1. サーバーを新規作成する

1. Discordへ所有者アカウントでログインする。
2. 左側のサーバー一覧にある「サーバーを追加」または `+` を押す。
3. 「オリジナルの作成」を選ぶ。用途の質問が出た場合はコミュニティ向けを選ぶ。
4. サーバー名へ `妖怪将棋 公式コミュニティ` を入力する。
5. 用意したサーバーアイコンを設定して「作成」を押す。
6. サーバー名を押して「サーバー設定」を開き、所有者が想定したアカウントか確認する。
7. タイムゾーンを設定できる画面では `Asia/Tokyo` を選ぶ。イベント本文にも必ず日本時間と書く。

作成直後に表示される招待リンクはまだ公開しない。権限と安全設定を完了する前に一般ユーザーを
招待すると、初期チャンネルへの書き込みや不要な招待リンク作成を許す可能性がある。

## 2. 最初に安全設定を行う

「サーバー設定」で次を設定する。項目名はDiscordの更新で変わることがある。

### 2.1 基本設定

- デフォルト通知を「メンションのみ」にする。
- システム参加メッセージを後で作成する `#参加・退出` へ集約するか、表示を無効にする。
- サーバー内で不在チャンネルへの自動移動が設定できる場合は、ボイスチャンネルを作るまで無効にする。

### 2.2 モデレーション・安全設定

- 認証レベルは「高」を初期値とし、メール認証済みアカウントを要求する。
- メディアコンテンツフィルターは全メンバーを対象にする。
- DMスパムや不審なメッセージを検出する安全機能を有効にする。
- 管理操作を行うロールには多要素認証を必須にする。

参加障壁が原因で参加率が著しく落ちた場合も、認証レベルを下げる前にログで原因を確認する。
公開サーバーでは安全性を優先し、電話番号必須の最高レベルは荒らし発生時の一時措置とする。

### 2.3 `@everyone` の権限

「ロール」から `@everyone` を開き、次を無効にする。

- サーバー管理、チャンネル管理、ロール管理
- メッセージ管理、メンバーのキック・BAN・タイムアウト
- Webhook管理、外部アプリ管理
- `@everyone` / `@here` / 全ロールへのメンション
- ニックネーム管理
- 招待の作成

「チャンネルを見る」「メッセージ履歴を見る」は許可する。メッセージ送信権限はカテゴリー単位で
付与する。管理者権限は所有者以外へ原則付与しない。

## 3. ロールを作成する

「サーバー設定 → ロール」で上から次の順に作る。ロールの並び順は権限行使の対象範囲に影響するため、
`運営` と `モデレーター` を一般ロールより上に置く。

| ロール | 付与方法 | 権限 |
|---|---|---|
| `運営` | 所有者が手動付与 | 設定・チャンネル・ロール・イベント管理。付与は最少人数 |
| `モデレーター` | 所有者が手動付与 | メッセージ管理、タイムアウト、キック。サーバー管理は付与しない |
| `対戦会通知` | オンボーディングで本人が選択 | 特別な管理権限なし。対戦会通知のメンション先 |
| `メンバー` | オンボーディング完了時 | 通常チャンネルで送信・リアクション・スレッド利用 |

確認手順:

1. `モデレーター` に「管理者」を付けない。
2. `対戦会通知` から全管理権限を外す。
3. `運営` だけが `#お知らせ` へ投稿できる状態にする。
4. Discordの「ロールとしてサーバーを表示」機能があれば各ロールの見え方を確認する。

## 4. カテゴリーとチャンネルを作成する

自動作成された不要なチャンネルは、以下を作って権限確認した後に削除する。

### 4.1 カテゴリー構成

```text
はじめに
  #はじめに
  #ルール
  #お知らせ
  #参加・退出

対戦
  #対戦募集
  #対戦会
  #攻略・編成

サポート
  #感想・不具合報告

運営（非公開）
  #運営ログ
```

### 4.2 権限設定

カテゴリー側で権限を設定し、配下のチャンネルへ同期する。

| カテゴリー・チャンネル | `@everyone` / `メンバー` | `運営` | `モデレーター` |
|---|---|---|---|
| `#はじめに` `#ルール` `#お知らせ` | 閲覧・履歴のみ | 投稿可 | `#お知らせ`は原則投稿不可 |
| `#参加・退出` | 閲覧のみ | 管理可 | 管理可 |
| `対戦`カテゴリー | 閲覧・投稿・リアクション・スレッド可 | 管理可 | メッセージ管理可 |
| `#感想・不具合報告` | 閲覧・投稿可 | 管理可 | メッセージ管理可 |
| `運営`カテゴリー | 閲覧不可 | 閲覧・投稿可 | 閲覧・投稿可 |

`#対戦募集` は低速モードを5秒程度に設定する。荒らしが発生した場合は一時的に30秒以上へ変更する。
ファイル添付は攻略画像に必要なチャンネルだけ許可し、実行形式ファイルなど不審な添付は削除する。

## 5. コミュニティ機能を有効にする

「サーバー設定 → コミュニティを有効化」から案内に従う。

1. Discordが要求する認証レベルとメディアフィルターを確認する。
2. ルール・ガイドラインのチャンネルに `#ルール` を指定する。
3. コミュニティ更新または運営向け通知チャンネルに `#運営ログ` を指定する。
4. サーバーの主な言語を日本語にする。
5. コミュニティ機能を有効にする。

公開サーバー検索への掲載は初期には申請しない。まず招待制でモデレーション負荷と対戦流動性への
効果を検証する。

### 5.1 参加時の案内・オンボーディング

オンボーディングまたはサーバーガイドが利用できる場合は次を設定する。

- デフォルトチャンネル: `#はじめに`、`#お知らせ`、`#対戦募集`、`#攻略・編成`
- 最初に行うこと: ルール確認、ゲームを開く、対戦会通知の選択
- 質問: 「公式対戦会の通知を受け取りますか？」
- 選択肢「受け取る」で `対戦会通知` を付与し、「受け取らない」では付与しない

オンボーディングを使えない場合は `#はじめに` の固定投稿で同じ内容を案内し、通知ロールは
運営がリアクション等を確認して手動付与する。自己紹介や発言を参加条件にしない。

## 6. AutoModを設定する

「サーバー設定 → AutoMod」または安全設定から、利用できるルールを有効にする。

- メンションスパムを遮断し、一度に許可するメンション数を5以下にする。
- Discord標準の不適切語句・スパム検出を有効にする。
- カスタムキーワードへ、認証情報や引き継ぎコードの投稿を促す典型表現を追加する。
- 遮断時の通知先を `#運営ログ` にする。
- 繰り返し違反へタイムアウトを適用する場合は、最初は短時間にして誤検知を確認する。

ゲーム用語を誤検知しないか、公開前に一般権限のテストアカウントで確認する。AutoModだけに依存せず、
通報を確認する担当者を公式対戦会中に1人決める。

## 7. 初期文章を投稿する

### 7.1 `#はじめに`

```text
妖怪将棋 公式コミュニティへようこそ。

無料・登録不要のブラウザ対戦ゲームです。
ゲーム: https://yokai-shogi.nit-games.com/?utm_source=discord&utm_medium=community&utm_campaign=server_guide

ランダムマッチはいつでも利用できます。毎日20:00〜22:00は「逢魔が時」で、対戦相手が集まりやすい時間です。
毎週土曜21:00〜22:00に公式対戦会を開催します。

1. #ルール を確認
2. #対戦募集 で参加時刻を確認
3. 指定時刻にゲームの「ランダムマッチ」を選択

発言や自己紹介は必須ではありません。認証トークン、引き継ぎコード、個人情報は投稿しないでください。
```

### 7.2 `#ルール`

```text
1. 暴言、嫌がらせ、差別的表現、スパムを禁止します。
2. チート、不具合の悪用、勝ち譲り、複数アカウントでの報酬獲得を禁止します。
3. 本人の同意なく個人情報、DM、対戦結果を公開しないでください。
4. 認証トークンや引き継ぎコードを投稿しないでください。運営が提示を求めることもありません。
5. 対戦募集は [ランダム] または [フレンド] を先頭に付けてください。
6. 違反時は投稿削除、注意、書き込み制限、退出等を行います。

利用規約: https://yokai-shogi.nit-games.com/legal/terms.html
プライバシーポリシー: https://yokai-shogi.nit-games.com/legal/privacy.html
```

### 7.3 `#対戦募集` の固定投稿

```text
[ランダム] 21:15開始 / 参加できる方は⚔️で反応してください
ゲーム: https://yokai-shogi.nit-games.com/?utm_source=discord&utm_medium=community&utm_campaign=match_hour

[フレンド] 21:30開始 / 参加希望者へスレッド内でルームコードを共有します
```

投稿後、各文章を固定する。URL、時刻、ルール番号が本書と一致することを確認する。

## 8. 公式対戦会イベントを作成する

1. サーバー名またはイベント欄から「イベントを作成」を選ぶ。
2. 開催場所は `#対戦会`、または外部リンクを選べる場合はゲームURLを指定する。
3. イベント名を `妖怪将棋 公式対戦会` とする。
4. 開始を土曜21:00、終了を22:00、日本時間として設定する。
5. 説明へゲームURL、20:45集合、ランダムマッチへ同時参加する旨を記載する。
6. 用意できれば対戦会用画像を設定し、イベントを公開する。
7. `#お知らせ` へイベントを共有する。通知は `対戦会通知` のみに送る。

イベントは原則3日前に作成し、当日20:45と21:00以外には一斉通知しない。

## 9. 招待リンクを作成する

設定完了後、`#はじめに` から招待を作成する。

1. 招待リンクの期限を「無期限」、使用回数を「無制限」にする。
2. 一時メンバー設定は無効にする。
3. 公式サイト・公式X用に別々の招待リンクを作り、流入元を区別できるよう記録する。
4. 招待リンク、作成日、用途、作成者を運用台帳へ記録する。
5. 一般権限のテストアカウントで参加し、最初に `#はじめに` が表示されることを確認する。

流出・スパム流入が起きた招待リンクは無効化して再発行する。第三者が作る招待を抑えるため、
`@everyone` と `メンバー` には「招待の作成」を付与しない。

## 10. 公開前テスト

所有者とは別のテストアカウントで次を確認する。

- [ ] 招待リンクから参加できる
- [ ] `#はじめに`、`#ルール`、`#お知らせ` を閲覧でき、投稿はできない
- [ ] `#対戦募集` と `#感想・不具合報告` へ投稿できる
- [ ] `#運営ログ` は存在自体が見えない
- [ ] `@everyone` や `@here` をメンションできない
- [ ] 招待リンクを新規作成できない
- [ ] `対戦会通知` を希望した人だけが通知対象になる
- [ ] AutoModがメンションスパムを遮断し、通常のゲーム用語は遮断しない
- [ ] ゲームURLからゲームが開き、異なる2アカウントでランダムマッチが成立する
- [ ] スマートフォンからも主要チャンネルとイベントを確認できる

権限不備が1件でもあれば公開しない。修正後に同じテストアカウントで再確認する。

## 11. 公開手順

1. `#お知らせ` にサーバー開設と初回対戦会を投稿する。
2. 公式サイトへDiscord招待リンクを掲載する。
3. 公式Xでゲームへの直接リンクとDiscord招待リンクの両方を案内する。
4. 初回24時間は運営またはモデレーターが定期的に `#運営ログ` と通報を確認する。
5. 初回対戦会終了後、参加数、キュー参加、成立率、問題報告を記録する。

Discord参加をゲームプレイの必須条件にしない。X投稿から直接ゲームへ参加できる導線を残す。

## 12. 定例運用

### 毎日

- スパム、通報、AutoMod通知を確認する。
- 20:00前後の対戦募集があれば5分単位の同時参加を補助する。
- 障害時は `#お知らせ` で募集停止と代替手段を案内する。

### 毎週

- 土曜対戦会イベントを3日前までに作成する。
- Discord告知後30分の `queue_join`、成立率、AI切替率を記録する。
- 期限切れ情報、固定投稿、ゲームURLを確認する。
- モデレーション件数と対応漏れを確認する。

### 毎月

- 運営・モデレーターロールの付与対象を棚卸しする。
- 不要なBot、連携アプリ、Webhook、招待リンクを削除する。
- ルール、安全設定、バックアップコードの保管状況を確認する。
- チャンネル追加は実際の投稿量が既存チャンネルで扱えない場合だけ検討する。

初期運用ではBotを導入しない。手作業で運用量を把握し、対戦会通知や集計が継続的な負担に
なった時点で、必要な権限を限定したBotを検討する。

## 13. 問題発生時の対応

| 事象 | 初動 |
|---|---|
| スパム流入 | 問題の招待を無効化、低速モード強化、認証レベルを一時的に上げる |
| 暴言・嫌がらせ | 証拠を運営ログへ記録、投稿削除、注意またはタイムアウト |
| 個人情報・認証情報の投稿 | 即時削除、本人へ認証情報の更新を案内、内容を運営ログへ転載しない |
| ゲーム障害 | 対戦募集を停止、`#お知らせ` とXで告知、復旧確認後に再開 |
| 所有者アカウント侵害 | Discordの復旧手順を実施し、連携アプリ・Webhook・ロールを監査 |
| モデレーター権限の誤用 | 権限を外し、監査ログを保存して所有者が事実確認する |

ゲーム内BANとDiscord上の措置は自動連動させない。証拠、対象規約、影響範囲をそれぞれ確認し、
必要な場合だけ個別に実施する。
